# Contributing

Thank you for your interest in this project!

**This is an architecture case study** — documentation and diagrams describing a production-grade AI system for brand consistency. It is not runnable software.

## How to Contribute

- **Questions about the architecture?** Open an [Issue](../../issues) using the "Architecture Question" template
- **Spot an error or inconsistency?** Open an Issue with the specific file and line
- **Want to discuss a design trade-off?** Open an Issue describing the alternative approach

## What This Repo IS

- An architecture specification with OpenAPI contracts and SQL schemas
- A scientific methodology paper on LOCKED/UNLOCKED LoRA training
- UX flow documentation for dual-persona (Creator + Data Scientist) interfaces
- A reference for system design interviews and technical discussions

## What This Repo IS NOT

- Runnable code or a deployable application
- A tutorial on how to train LoRAs (see references in [05-RELATED-WORK.md](paper/05-RELATED-WORK.md))
- A product pitch or sales material
